# THE ARRAY · Personal Machine Command

An independent science-fiction command centre for PARALLAX, Lhündrup, BLACK STATIC, FIRST CONTACT, NEURO//LAB and HONEYLARK. Built with **HTML, CSS and JavaScript** and hosted on GitHub Pages. No Lovable, paid services or build tooling.

## Launch

The entire application is inside [index.html](index.html); there are no JavaScript or stylesheet dependencies to install. PWA metadata, icon and offline caching are included. On GitHub, go to **Settings → Pages → Deploy from a branch**, select `main` and `/ (root)`, then Save. Site: https://levitatingsnake.github.io/The-array/

For iPhone Home Screen use Safari → Share → Add to Home Screen once the GitHub Pages site is published.

## GO buttons

GO currently runs actual local browser computations against synthetic or illustrative data, with event feeds, results and saved history. These are **not** live invocations of your private GitHub/Python research engines. Each machine clearly identifies its local laboratory mode. Live GitHub Actions integration requires an authenticated, server-side runner; do not put a GitHub token in this public repository or in browser JavaScript.

## Privacy

This is a public GitHub Pages website. Code, the visible machine names and public documentation are visible to anyone who accesses the repository. Your other private repositories and their data are not exposed by merely linking to them. Local run history stays in the browser where it was created.

## Full modular source

A modular distribution, automated tests and assets are available in the original THE_ARRAY_Web_App.zip created alongside this project. This repository uses its **standalone HTML build** for the simplest possible deployment.
