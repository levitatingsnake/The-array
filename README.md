## Launch
The entire application is in `index.html`. GitHub Pages: repository **Settings → Pages**, source **main**, folder **/(root)**. Site: https://levitatingsnake.github.io/The-array/

For iPhone, open the site in Safari and use Share → Add to Home Screen. If you already installed the previous icon, remove the old Home Screen shortcut and add it again after the updated site appears, since iOS may keep the old icon.

## What GO does
GO executes genuine local/browser-side computational demonstrations on *synthetic or illustrative* data with steps, results and history. It **does not** trigger private GitHub/Python research engines. Live connections would require a secure, separately authorized backend; never place tokens in this public GitHub Pages repository.

## Source and privacy
The site and artwork are public, your private engine repositories are not. Local run history lives in your browser storage. Clearing website data removes it.

## ChatGPT development bridge (V3)

Select a machine, then **CONTINUE DEVELOPMENT** to open its associated private ChatGPT Project or exact development chat. Set up each link once by opening the Project in ChatGPT, copying the browser address (for example, a URL shaped like `https://chatgpt.com/g/g-p-.../project`), and pasting it into that machine's Development Bridge. A direct current-chat URL is optional.

- The app only opens saved links. It cannot retrieve private Project IDs, read conversation content, inject messages or automatically synchronise ChatGPT progress.
- The links are stored **only in localStorage on your device**, not committed to this public GitHub repo. Set them again if you reinstall or use a different browser.
- **Do not use Share → Anyone with a link** merely to connect the app. A personal Project URL does not require making the project public.
- **COPY DEVELOPMENT HANDOFF** creates an optional brief including the project's repository and the most recent *local* synthetic Array run for manual pasting in ChatGPT.
- Computational GO controls remain browser-local, unconnected to live Python/GitHub workflows.
