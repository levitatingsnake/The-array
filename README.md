# THE ARRAY · Personal Machine Command

Independent HTML/CSS/JavaScript command centre for PARALLAX, Lhündrup, Black Static, First Contact, NEURO//LAB and Honeylark. No Lovable, framework or paid build tools.

## Launch
Everything needed is in `index.html`, `manifest.webmanifest`, `service-worker.js` and the `assets/` directory. No build step. GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**.

Site: https://levitatingsnake.github.io/The-array/

On iPhone, open in Safari and use **Share → Add to Home Screen**. If the old icon remains from an earlier install, remove the old Home Screen shortcut and add it again. iOS can retain older shortcut artwork even when a website updates.

## GO buttons and research integrity
GO runs genuine **browser-local algorithms** with synthetic/illustrative data, recorded stages and computed results. GO **does not** launch private GitHub/Python engines. Live backend workflow integrations require secure server-side authorization. Never put GitHub tokens in this public repository or browser JavaScript.

## Privacy
This repository and artwork are public; private engine source code is not included. Run history is saved locally on the device and may be lost if site data is cleared.
